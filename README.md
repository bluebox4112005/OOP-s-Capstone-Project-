OOP's Capstone Project – E-Locker System
This project is a Java-based E-Locker System developed as a capstone project for Object-Oriented Programming (OOP) coursework. It provides a secure platform for users to store and manage digital documents efficiently.

Features
User Management: Register new users and authenticate existing ones.

Document Handling: Upload, download, and delete personal documents securely.

Graphical User Interface (GUI): Interactive interface built using Java Swing.

Data Persistence: Utilizes an SQLite database (elocker.db) for storing user data and document metadata.

Modular Architecture: Structured using OOP principles for scalability and maintainability.
